# 学生監査管理システム 利用案内

監査員がGoogleフォームへ入力し、本部が監査結果を確認・PDF出力するための手順です。

本部から案内されたURLと、利用を許可された学校のGoogleアカウントを使います。別のパソコンからも同じURLで利用できます。通常利用にインストールやGitHubアカウントは必要ありません。

団体・監査項目を編集する運用管理者は、[本部・運用管理者向けの手順](OPERATIONS.md)を参照してください。

## 使う画面

| 担当 | 開く画面 | できること |
|---|---|---|
| 監査員 | 監査員用Googleフォーム | 監査結果の入力・送信 |
| 本部メンバー | 本部管理画面 | 記録の閲覧・詳細確認・PDF出力 |
| 本部管理者 | 本部管理画面 | 本部メンバーの機能に加え、利用者の登録・権限変更・削除 |

画面のURLは本部から受け取ってください。学校アカウントでも、各画面の利用者登録が必要です。この案内の公開だけでは利用権限は付きません。

## 監査員：監査結果を入力する

1. 自分の学校アカウントで監査員用フォームを開きます。
2. 「監査対象団体」を選びます。候補にない場合は本部へ連絡します。
3. 「監査員氏名」を入力します。複数人の場合は、1行に1名ずつ全員を記入します。
4. 「監査実施日」に、実際に監査した年・月・日を入力します。
5. 各監査項目をA〜Dで評価します。
6. 必要な内容を最後の「特筆事項」に記入します。なければ空欄にできます。
7. 内容を確認して「送信」を1回押し、受付完了の表示を待ちます。

| 評価 | 基準の目安 |
|---|---|
| A | 51〜100% |
| B | 26〜50% |
| C | 11〜25% |
| D | 0〜10% |

割合は評価基準の目安です。合計点や総合評価は自動計算しません。具体的な判断は、学校内で確認した基準に従ってください。

送信後の誤りや、送信できたか分からない場合は、団体名・実施日・監査員氏名を本部へ伝えます。確認せずに再送すると、別の監査記録として保存されます。送信済みの回答を自分で編集する機能はありません。

## 本部：監査記録を見る

1. 自分の学校アカウントで本部管理画面を開きます。
2. 上部のメールアドレスが自分のものか確認します。
3. 「年度」と「期間」を選びます。期間は年度全体・上半期・下半期から選べます。
4. 記録の「詳細」を開き、監査項目・評価・特筆事項を確認します。
5. 新しい送信を読み直すときは「更新」を押します。

| 期間 | 対象となる監査実施日 |
|---|---|
| 年度全体 | 4月1日〜翌年3月31日 |
| 上半期 | 4月1日〜9月30日 |
| 下半期 | 10月1日〜翌年3月31日 |

年度・期間は「監査実施日」で決まります。送信した日とは異なる場合があります。

年度別の対象団体は、監査済み・未監査の両方が表示されます。記録のない対象には「未監査」と表示されます。半期を選んだ場合は、その半期に記録がないことを表します。同じ団体を複数回監査した場合は、それぞれ別の記録です。

「対象台帳が未登録です」と表示された年度は、対象一覧の整備が必要です。すべて監査済みとは判断せず、運用管理者へ確認してください。

## 本部：報告書を作成する

### 監査1件を出力する

1. 一覧で対象の「詳細」を開きます。
2. 団体名・実施日・監査員を確認します。
3. 「この監査の報告書を作成」を押します。
4. 対象を確認し、「PDFを作成」を押して完了を待ちます。
5. 表示された閲覧・ダウンロードリンクからPDFを開きます。

### 年度・半期をまとめて出力する

1. 一覧上部の「報告書を作成」を押します。
2. 年度と期間を選び、表示された対象件数を確認します。
3. PDFを作成し、完了後のリンクから開きます。

PDFはGoogle Driveへ保存されます。印刷はA4・縦が基本です。未監査の団体の空の報告書は作成しません。個別出力でも、長い内容は複数ページになる場合があります。

一度に50件まで出力できます。年度全体が上限を超える場合は半期に分けます。PDF作成中にエラーが出た場合は、再作成する前に保存先を確認してください。

## 困ったとき

| 状況 | 確認すること |
|---|---|
| 本部画面に入れない | 学校アカウントで開いているか、本部として登録されているか |
| フォームへ回答できない | 監査員登録と、回答受付の状態 |
| 送信した記録が見つからない | 実施日の年度・期間を確認して「更新」。再送は本部の確認後 |
| PDFを開けない | 作成時と同じ学校アカウントか、Driveの閲覧権限があるか |
| PDF作成でエラーが出る | 保存先に完成したPDFがないか確認し、表示内容を運用管理者へ伝える |

障害時は、発生日時・使ったアカウント・画面名・実行した操作・表示されたエラーを本部または学校内の案内に記載された連絡先へ伝えてください。パスワードや認証コードは送らないでください。

スマートフォンでも開けます。本部の横長の一覧は横スクロールになるため、まとめた確認や帳票操作にはPC・タブレットが便利です。

## この案内の位置づけ

システムはGoogleフォーム・Googleスプレッドシート・Google Apps Script上で動作します。GitHubはこの使い方を置く場所です。団体・監査項目の変更はGoogleフォームで行い、プログラム自体の修正は運用管理者がApps Script側で行います。

学校内の接続先・連絡先・監査データは、この公開案内には掲載していません。
