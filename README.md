# 学生監査管理システム 利用案内

本部から案内されたURLと、自分の学校Googleアカウントを使います。別のパソコンからも同じURLで利用できます。通常利用にインストールやGitHubアカウントは必要ありません。

利用者の登録や団体・項目の変更は、[管理担当者向け手順](OPERATIONS.md)を参照してください。

## ロールと利用範囲

| ロール | 利用できること |
|---|---|
| システム所有者 | 全ての業務操作。削除・降格・期限設定不可 |
| 学友会 | 全ての業務操作。所有者の権限は変更不可 |
| 監査委員長 | 監査入力・閲覧・PDF作成・受付期設定、別の委員長と監査委員の管理 |
| 監査委員 | 監査入力・閲覧・PDF作成 |
| 先生 | 監査記録の一覧と詳細の閲覧のみ |

学校アカウントでも利用者登録が必要です。氏名は登録時に手入力します。一覧では氏名を主に、その下にメールの@より前を表示します。同姓同名はアカウント名で区別します。

## 監査結果を入力する

1. 案内されたフォーム、または本部画面の「監査を入力」を開きます。
2. 監査対象団体を選び、監査員氏名を入力します。複数人の場合は1行に1名ずつ全員を記入します。
3. 各項目をA〜Dで評価し、必要なら最後の特筆事項を記入します。
4. 内容を確認して送信を1回押し、受付完了の表示を待ちます。

| 評価 | 基準の目安 |
|---|---|
| A | 51〜100% |
| B | 26〜50% |
| C | 11〜25% |
| D | 0〜10% |

総合評価は自動計算しません。判断は学校内の基準に従います。日付の入力は不要です。送信日時を日本時間で記録し、本部が設定した受付年度・前期／後期に保存します。過去の記録は受付期を変えても変わりません。旧方式の記録には手入力した監査実施日が残ります。

誤りや送信の成否が不明な場合は、団体名・送信日時・監査員氏名を本部へ伝えます。確認せず再送すると別の監査記録になります。送信済み回答を自分で編集する機能はありません。

## 監査記録を見る

1. 自分の学校アカウントで本部画面を開きます。
2. 初期表示は日本時間での現在の年度・年度全体です。年度は4月始まりです。
3. 必要に応じ年度と期を選びます。全年度を見るときは「すべての年度」にします。
4. 詳細で当時の項目・評価・特筆事項を確認します。新しい送信を読み直すときは更新を押します。

更新では選んだ年度・期を維持します。年度別の全対象を表示し、記録がない団体は未監査と表示します。半期を選ぶと、その半期に記録がないことを表します。同じ団体の複数回の監査は別記録です。

対象台帳が未登録と表示された年度は、対象一覧の整備が必要です。すべて監査済みとは判断せず運用管理者へ確認してください。先生は一覧・詳細の閲覧のみで、監査入力・PDF作成・管理操作はできません。

## 報告書を作成する

先生以外の登録者が利用できます。

- 1件だけ出すときは、詳細で団体・日時・監査員を確認し「この監査の報告書を作成」を押します。
- まとめて出すときは、上部の「報告書を作成」で年度と期を指定します。
- 件数と対象を確認してPDFを作成し、完了後の閲覧・ダウンロードリンクから開きます。

PDFはGoogle Driveへ保存します。印刷はA4・縦が基本です。未監査の空の報告書は作りません。長い記録は複数ページになる場合があります。一度に50件までで、上限を超えたら半期に分けます。作成エラー時は再作成する前に保存先を確認します。

## 困ったとき

入れないときは学校アカウント・登録・利用期間を確認します。記録が見つからないときは受付年度・期を確認して更新します。氏名未登録と出た場合は管理者に氏名登録を依頼します。PDFを開く際は作成時と同じ学校アカウントを使います。

障害時は発生日時・アカウント・画面名・操作・エラー表示を、学校内の案内にある連絡先へ伝えます。パスワードや認証コードは送りません。

スマートフォンでも開けます。横長の一覧は横スクロールになるため、まとめた確認や帳票操作にはPC・タブレットが便利です。この公開案内には学校内の接続先・連絡先・監査データを掲載していません。
